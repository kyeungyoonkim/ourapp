# 우리만의 공간 💕

남자친구와 둘만의 모바일 친화적 커플 웹앱이에요.

## 기능

- **홈** — 함께한 날 수, 다음 만남 D-day, 각자 타임존 시계
- **여행 지도** — 함께 갔던 곳을 지도에 핀으로 표시
- **추억** — 타임라인으로 소중한 순간 기록
- **쪽지** — 롱디용 사랑 쪽지 남기기
- **버킷리스트** — 같이 하고 싶은 것들 체크
- **설정** — 이름, 기념일, 도시, 타임존, 다음 만남 날짜

데이터는 브라우저 `localStorage`에 저장돼서 서버 없이 바로 쓸 수 있어요.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속하세요.

## 폰에서 쓰기

1. 같은 Wi-Fi에서 PC IP로 접속 (예: `http://192.168.0.10:5173`)
2. 또는 `npm run build` 후 [Vercel](https://vercel.com) / [Netlify](https://netlify.com)에 무료 배포
3. 폰 브라우저에서 "홈 화면에 추가" 하면 앱처럼 쓸 수 있어요

## 커스터마이즈

앱 안 **더보기 → 커플 설정**에서 이름, 기념일, 타임존 등을 바꿀 수 있어요.
